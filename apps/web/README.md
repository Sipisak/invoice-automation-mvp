# apps/web — SPFx webpart (Invoice Review)

This folder is **intentionally not scaffolded by hand**. SPFx must be generated by the
Yeoman generator so certs, gulp config and bundling are correct.

## Scaffold (once)

```bash
cd apps/web
nvm use 18
npx yo @microsoft/sharepoint
#   Solution name: invoice-review
#   Component type: WebPart
#   Framework: React
#   Web part name: InvoiceReview
gulp trust-dev-cert      # one-time, accept the local cert
```

Then drop `src/client/invoicesClient.ts` (already in this folder) into the generated
`src/webparts/invoiceReview/api/` and build the UI per `CLAUDE.md` Day 5.

## Run (local workbench + backend)

```bash
# terminal 1 – backend
cd ../../apps/api && pnpm start          # http://localhost:7071

# terminal 2 – SPFx
cd apps/web && gulp serve                # https://localhost:4321/temp/workbench.html
```

CORS for `https://localhost:4321` is already set in `apps/api/local.settings.json`.

> ponytail: web stays a standalone npm project (NOT in the pnpm workspace) — SPFx + gulp
> break under pnpm's symlinked node_modules.
